## 1. Introduccion

GitHub CLI es una herramienta de linea de comandos que permite administrar repositorios de GitHub sin necesidad de utilizar directamente el sitio web. Con esta herramienta se pueden crear repositorios, clonar proyectos, crear ramas, realizar commits, subir cambios y administrar repositorios desde la terminal.
